How to Install & Print

1
Download & Install EasyPrint APK
Tap Download EasyPrint APK above, open the downloaded file on your Android phone, and allow installation when prompted.
2
Enable HP Print Service Plugin
Install HP Print Service Plugin from Google Play and turn it ON in Android Settings → Printing.
3
Connect HP Ink Tank 315 via USB OTG
Plug the printer into your phone with a USB OTG cable, share any PDF or photo from WhatsApp to EasyPrint, and tap PRINT.
